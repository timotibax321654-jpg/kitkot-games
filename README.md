# Kitkot Games

Дипломный проект: Fullstack веб-платформа с интегрированной 2D-игрой на Unity.

## Описание проекта
Проект представляет собой веб-платформу, где пользователи могут зарегистрироваться, войти в личный кабинет, посмотреть таблицу лидеров и поиграть в 2D-игру (сбор монеток) прямо в браузере. Результаты игр сохраняются в базе данных и отображаются в истории профиля.

## Технологии
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Backend:** Node.js, Express.js
*   **База данных:** PostgreSQL (библиотека `pg`)
*   **Аутентификация:** JWT (JSON Web Tokens), bcryptjs (хеширование паролей)
*   **Игровой движок:** Unity 6 (2D, WebGL сборка)
*   **Логирование:** Morgan, Winston

## Как запустить проект локально

### Предварительные требования
*   Установленный Node.js
*   Установленный PostgreSQL (создана база `kitkot_games`)

### Установка
1. Клонируйте репозиторий:
   `git clone https://github.com/timotibax321654-jpg/kitkot-games.git`
2. Перейдите в папку сервера:
   `cd server`
3. Установите зависимости:
   `npm install`
4. Создайте файл `.env` в папке `server` и заполните его (пример есть в `server/.env.example` или запросите у автора).
5. Запустите сервер:
   `npm run dev`

### Использование
1. Откройте браузер и перейдите по адресу: `http://localhost:3000`
2. Зарегистрируйте нового пользователя.
3. В личном кабинете вы увидите встроенную игру. Играйте и нажимайте кнопку "Save" для сохранения результата в базу!

## Структура проекта
*   `client/` — фронтенд (HTML, CSS, JS) и файлы WebGL-сборки игры (`client/Game`)
*   `server/` — бэкенд на Node.js (маршруты API, middleware, подключение к БД)
*   `kit-kotGame/` — исходный проект Unity (скрипты, сцены, ассеты)
